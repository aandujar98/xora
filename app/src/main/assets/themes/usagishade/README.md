# UsagiShade theme pack

Pink and Dark share one soundtrack. Each variant has its own looping wallpaper.

| File | Role |
|------|------|
| `themes/usagishade/bgm.mp3` | Looping BGM for both UsagiShade (Pink) and UsagiShade (Dark) |
| `themes/usagishade_pink/wallpaper.mp4` | Pink motion backdrop (`Motion BG.mp4`) |
| `themes/usagishade_dark/wallpaper.mp4` | Dark motion backdrop (`BG Dark.mp4`) |

Replace `wallpaper.mp4` in either folder with your own loop (muted; the shell ignores video audio). Rebuild after swapping files.
