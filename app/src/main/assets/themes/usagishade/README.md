# UsagiShade theme pack

Pink (shown as **Usagi Reload**) and Dark share one soundtrack. Each variant has its own looping wallpaper.

| File | Role |
|------|------|
| `themes/usagishade/bgm.mp3` | Looping BGM for both Usagi Reload and UsagiShade (Dark) |
| `themes/usagishade_pink/wallpaper.mp4` | Usagi Reload motion backdrop (`USAGI.3.RELOAD_LOOP.mp4`, GitHub tag `usagi-reload`) |
| `themes/usagishade_dark/wallpaper.mp4` | Dark motion backdrop (`BG Dark.mp4`) |

Replace `wallpaper.mp4` in either folder with your own loop (muted; the shell ignores video audio). Rebuild after swapping files.
